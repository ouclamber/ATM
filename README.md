# ATM

[![CI](https://github.com/ouclamber/ATM/actions/workflows/ci.yml/badge.svg)](https://github.com/ouclamber/ATM/actions/workflows/ci.yml)

Консольный симулятор банкомата на .NET 10. Позволяет клиенту снимать и вносить наличные, переводить деньги между картами, смотреть историю операций. Администратор может управлять кассетами банкомата.

## Возможности

### Для клиента
- 🔐 Вход по номеру карты и PIN-коду
- 💰 Проверка баланса
- 💵 Снятие наличных (с выбором купюр)
- 💳 Внесение наличных
- 🔄 Перевод средств на другую карту
- 📋 История операций за 30 дней
- 🔑 Смена PIN-кода
- ℹ️ Информация о банкомате

### Для администратора
- 🔒 Вход по логину и паролю
- 📊 Просмотр состояния кассет
- 📥 Инкассация (пополнение кассет)
- 🧮 Расчёт выдачи купюр

### Безопасность
- PIN-коды хранятся в виде BCrypt-хэшей
- Блокировка карты после 3 неудачных попыток ввода PIN
- Дневной лимит снятия — 50 000 ₽
- Маскирование номера карты в интерфейсе
- Логирование всех операций в файлы

## Системные требования

- **.NET 10 Runtime** — [скачать](https://dotnet.microsoft.com/download/dotnet/10.0)
- **PostgreSQL 12+** — [скачать](https://www.postgresql.org/download/)
- Windows / Linux / macOS

## Быстрый старт

### 1. Установить PostgreSQL

Скачайте и установите PostgreSQL. Запомните пароль пользователя `postgres`.

### 2. Создать базу данных

Откройте `pgAdmin` или `psql` и выполните:

```sql
CREATE DATABASE "ATM";
```

### 3. Настроить подключение

Откройте файл `Bankomat/appsettings.json` и укажите свои параметры подключения:

```json
{
  "ConnectionStrings": {
    "DefaultConnection": "Host=localhost;Port=5432;Database=ATM;Username=postgres;Password=ВАШ_ПАРОЛЬ"
  }
}
```

### 4. Запустить приложение

```bash
cd Bankomat
dotnet run
```

При первом запуске:
- Создадутся таблицы в базе данных
- Добавятся 3 тестовых клиента
- Создастся банкомат с 5 кассетами

## Как пользоваться

### Вход как клиент

1. Запустите приложение: `dotnet run`
2. Выберите **«Войти как клиент»**
3. Введите номер карты (16 цифр) и PIN-код
4. Выбирайте операции из меню

### Вход как администратор

1. Запустите приложение
2. Выберите **«Административная панель»**
3. Введите логин `admin` и пароль `admin123`
4. Управляйте кассетами банкомата

## Лимиты

| Операция | Лимит за раз | Дневной лимит |
|----------|--------------|---------------|
| Снятие наличных | 20 000 ₽ | 50 000 ₽ |
| Внесение наличных | 50 000 ₽ | — |
| Перевод | 100 000 ₽ | — |

Суммы снятия и внесения должны быть кратны 100 ₽.

## Где хранятся логи

Все операции записываются в файлы:

```
Bankomat/bin/Debug/net10.0/logs/bankomat-ГГГГММДД.log
```

Логи хранятся 30 дней, потом удаляются автоматически.

## Решение проблем

### «Не удалось подключиться к базе данных»

- Проверьте, что PostgreSQL запущен
- Проверьте строку подключения в `appsettings.json`
- Убедитесь, что база данных `ATM` создана

### «Ошибка при запуске — приложение уже запущено»

- Закройте предыдущее окно консоли
- Или перезагрузите компьютер

### «Сборка падает с ошибкой NU1605»

- Выполните `dotnet clean` и попробуйте снова
